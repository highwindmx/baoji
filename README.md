# 宝记（Baoji）

> 局域网宝宝成长记录系统 —— 喂养、睡眠、尿布、生长曲线、健康、事件、照片墙，一个页面全搞定。

为家庭场景设计的单宝宝记录应用：部署在家里的常开电脑上，手机 / 平板 / 电脑浏览器扫码即用，数据 100% 自持（SQLite 单文件 + 本地媒体归档），不经过任何云端。

## 功能特性

-   **喂养**：会话制记录（一场可含母乳/奶粉/混合多种奶），日总览 7 天折线图（奶量柱状 + 次数曲线）
-   **睡眠**：起止时间记录，7 天时长趋势
-   **尿布**：类型 / 便便描述 / 拍照存证，按日切换总览
-   **生长曲线**：WHO 儿童生长标准 LMS 百分位（3/15/50/85/97），跟随宝宝性别，支持缩放与悬停查值
-   **健康**：体温监测（曲线）→ 疫苗（国家免疫程序 + 一键登记 + 未来接种提醒）→ 用药（下次服药提醒）
-   **事件**：成长事件时间轴，未来日期事件自动转为概览提醒，可配图 / 配视频
-   **照片墙**：独立照片页，九宫格 + 全屏播放器（桌面左右箭头 / 移动端滑动翻页）
-   **概览**：今日统计、DOL 天数横幅、最近生长、未来 7 天提醒一屏尽览
-   **数据导出 / 导入**：Excel 9 分表导出 + 中文 PDF 报告；导入按内容**自动去重**，重复导入安全
-   **媒体归档**：`uploads/<宝宝名>/<日期>/event|diaper/` 按类型归档，每文件配同名 JSON 说明，支持本地手工拷贝 + 一键扫描重建索引
-   **移动端适配**：底部导航、防溢出布局、触屏翻页
-   **自动备份**：SQLite backup API 时间戳备份，超期自动清理

## 系统要求

-   Windows 10/11（其他平台自行适配启动脚本即可）
-   Python 3.11+
-   浏览器（Chrome / Edge / Safari，含移动端）

## 构建命令

```bat
:: 1. 创建虚拟环境并安装依赖
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

:: 2. 配置口令（首次运行前）
copy .env.example .env
:: 编辑 .env，修改 BABYWEB_PASSWORD 为强口令

:: 3. 启动
start.bat
```

启动后终端会打印局域网访问地址，手机连同一 Wi-Fi 即可打开；首启自动创建默认宝宝档案。

### 命令行参数

| 参数 | 说明 |
| --- | --- |
| --port 0 | 自动分配空闲端口 |
| --host 127.0.0.1 | 仅本机访问 |
| --no-auth | 关闭口令验证（仅限可信局域网） |

环境变量 `.env` 亦可配置同样内容（`BABYWEB_PASSWORD` / `BABYWEB_HOST` / `BABYWEB_PORT` / `BABYWEB_NOAUTH`），详见 `.env.example`。

## 使用说明对照表

| 页面 | 功能要点 |
| --- | --- |
| 概览 | 今日统计、最近生长、未来 7 天提醒（疫苗 / 用药 / 未来事件） |
| 喂养 | 新增一场 → 选类型填奶量（可多种混合）；图表查看 7 天趋势 |
| 睡眠 / 尿布 / 体温 / 用药 | 各自新增 + 日切换总览 + 历史列表（分页加载） |
| 生长 | 新增体重 / 身高 / 头围 → 曲线对照 WHO 百分位，标准随「设置」里性别联动 |
| 健康 | 疫苗页含免疫程序表：缺种一键登记、取消登记、自定义待办 |
| 事件 | 时间轴展示；新增可挂多图 / 视频；未来日期自动提醒 |
| 照片 | 全量媒体九宫格 + 全屏播放器 |
| 设置 | 宝宝信息、Excel 导入（自动去重）/ 导出、媒体扫描重建索引 |
| 工具 | 命令 |
| --- | --- |
| 数据库备份 | python tools/backup_db.py --keep 14（保留 14 天，超出自动清理） |
| 数据导出 | 设置页「导出 Excel / PDF」按钮 |
| 数据导入 | 设置页「导入 Excel」，按内容去重、只追加不覆盖 |

> **数据安全**：`data/baby.db`（SQLite WAL）与 `static/uploads/` 是全部私有数据，请定期备份且不要提交到公开仓库（`.gitignore` 已默认排除）。

## 技术栈

-   **后端**：Python · FastAPI · SQLAlchemy（sync）· SQLite（WAL）· Pydantic v2 · openpyxl · Pillow · ReportLab
-   **前端**：原生 HTML / CSS / JavaScript · ECharts（本地 vendored，离线可用）
-   **部署**：单机常驻，无外部服务依赖

## 目录结构

```
├── main.py            # FastAPI 应用与全部 API
├── database.py        # ORM 模型 + 建库 / 迁移
├── schemas.py         # Pydantic 模型
├── static/            # 前端 SPA（app.js / style.css / index.html / vendor）
├── tools/backup_db.py # 数据库备份脚本
├── data/              # 运行时数据（git 忽略）
└── static/uploads/    # 媒体归档（git 忽略）
```
